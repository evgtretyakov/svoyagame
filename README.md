# Своя Игра - Корпоратив

Упрощенная версия игры Jeopardy! для проведения корпоративного мероприятия. v2

## Функциональность

- **6 категорий** с вопросами стоимостью 200, 400, 600, 800, 1000 очков.
- **Каждый вопрос содержит текст ответа** (для ведущего).
- **Добавление игроков** помощницей перед началом игры.
- **Выбор текущего игрока** кликом по его имени в списке (удобно для ведущего).
- **Интерактивное игровое поле** — выбор категории и вопроса.
- **Таймер** 20 секунд на ответ. По истечении времени таймер останавливается, ответ показывается автоматически, но кнопки остаются активными (можно засчитать ответ после таймера).
- **Управление ответами**: кнопки "Ответ верный", "Ответ неверный", "Переход хода".
- **Кнопка "Показать ответ"** для досрочного открытия ответа.
- **Подсчет очков** в реальном времени.
- **Визуальное выделение** текущего игрока и отвеченных вопросов.
- **Сохранение состояния** в localStorage (игроки, очки, открытые вопросы) — при перезагрузке страницы игра продолжается.
- **Кнопка "Сбросить игру"** — очищает localStorage и полностью сбрасывает состояние.

## Технологии

- React 18 (функциональные компоненты, хуки)
- Context API для управления состоянием
- CSS модули (отдельные файлы стилей)
- Create React App (для сборки)

## Запуск в режиме разработки (dev mode)

1. Убедитесь, что установлены Node.js (версия 16 или выше) и npm.

2. Установите зависимости (если не установлены):
   ```bash
   npm install
   ```
   *Примечание:* если корпоративный npm-репозиторий блокирует пакеты, обратитесь к администратору для разрешения доступа.

3. Запустите dev-сервер:
   ```bash
   npm start
   ```

4. Откройте браузер по адресу [http://localhost:3000](http://localhost:3000).

5. Для отладки в браузере:
   - Используйте **DevTools** (F12) → вкладка **Console** для просмотра логов.
   - Вкладка **Sources** позволяет установить точки останова в исходном коде (файлы находятся в `src/`).
   - React Developer Tools (расширение для Chrome/Firefox) поможет инспектировать компоненты и состояние.

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы появятся в папке `build/`. Их можно развернуть на любом статическом хостинге.

## Как играть

1. **Добавьте игроков** через форму в левой панели.
2. **Нажмите "Начать игру"**.
3. **Текущий игрок** выбирает категорию и вопрос (клик по карточке с очками).
4. **Помощница** видит текст вопроса и запускается таймер.
5. **Помощница нажимает одну из кнопок**:
   - **Ответ верный** — игрок получает очки, ход переходит следующему.
   - **Ответ неверный** — очки не начисляются, ход переходит следующему.
   - **Переход хода** — выбор другого игрока для ответа (затем только верный/неверный).
6. Игра продолжается, пока не будут разыграны все вопросы.

## Возможные проблемы

- **Ошибка 403 при установке зависимостей**: корпоративный репозиторий блокирует некоторые пакеты. Обратитесь к администратору для настройки доступа или используйте разрешенный прокси.
- **Приложение не обновляет состояние**: убедитесь, что не используется кэширование. В dev-режиме Hot Reload работает автоматически.
